# Final_project

# Сервис Доска объявлений

## Описание проекта
Автоматизированные тесты для сервиса Доска объявлений

## Структура проекта
* **api** — классы для работы с API
* **data** — модели данных
* **pages** — Page Object классы
* **steps** — Step Definitions
* **utils** — вспомогательные классы

## Требования к окружению
* Java 11
* Maven
* Chrome/Chromedriver

## Запуск тестов
Для запуска тестов выполните:
```bash
mvn clean test
